# Malawi Ntchito Connect

A bilingual English/Chichewa, mobile-first employment and career support platform prototype for Malawi.

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.

## Important before launch
This is a frontend starter only. Demo vacancies and example organisations are placeholders, not verified live opportunities. The contact email shown in the prototype is a placeholder and must be replaced with a working address. Chichewa wording needs review by a fluent local speaker.

Before collecting applications or CVs, add a secure backend, authentication, employer verification, privacy notice and data protection controls. Add an admin dashboard and real vacancy workflow before public launch.
